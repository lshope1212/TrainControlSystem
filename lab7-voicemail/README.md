# Lab 7: Voicemail

Requires Python 3.8 or newer.

Open this folder and double-click `lab.cmd` to launch the menu.

- **1:** Test saving a new greeting.
- **2:** Test canceling a greeting change.
- **3:** Run all automated tests.
- **0:** Exit.

For options 1 and 2, follow the prompts. The result appears as `PASS` or `FAIL`.

To run the automated tests directly, open PowerShell in this folder and enter:

```powershell
.\lab.cmd test
```

Successful tests end with `PASS: all tests passed.`
