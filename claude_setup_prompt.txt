```text

```

```text

```

Similarly, the CTC TestUI should not show message class names such as:

```text

MaintenanceRequestMessage
BlockStatusMessage
```

in its communication status or captured outbound-message table.

Instead display:

```text

Maintenance request
Block status
```

This is strictly a **presentation/display change**.

DO NOT rename the actual message classes.

DO NOT change `MessageEnvelope.MessageType`.

DO NOT change serialization/deserialization behavior.

The internal communication layer should continue using class names such as `TicketSalesMessage` exactly as it does now.


